🌟 System Overview

A production-grade full-stack automation platform for auto-sharing Facebook posts to joined groups using Playwright browser automation, Node.js Express backend, and a real-time Web UI Dashboard with WebSocket streaming logs.

🔑 Core Capabilities
Active Features
  • 1-Click Facebook Authentication: Launches visible browser for safe manual login; session cookies stored in user_data/chrome_profile.
  • Real-Time Group Search & Presets: Instant group filtering, bulk select/deselect, and persistent JSON preset storage (user_data/group_presets.json).
  • Background Sharing Engine: Auto-posts to groups with custom captions, image cards, and link previews.
  • Dry-Run / Simulation Mode: Safely tests group post filling and link previews without clicking publish.
  • Anti-Spam De-duplication: Keeps history (user_data/share_history.json) with customizable cooldown periods (7–30 days).
  • WebSocket Log Stream: Live terminal log streaming from Playwright workers straight to the browser UI.
⚡ Quick Start & Run Commands
Developer Setup

1. Install Node dependencies:

npm install

2. Download Chromium browser binaries for Playwright:

npx playwright install chromium

3. Start server & open dashboard (http://localhost:3000):

npm start

4. Run automated test suite:

npm test

🔄 Execution Pipeline & Data Flow
Data Flow
  • Browser Session Persistence: Playwright launches Chromium using user_data/chrome_profile. Session cookies and local storage persist between restarts.
  • Group Discovery: Navigates to facebook.com/groups/joins, auto-scrolls the DOM, extracts group names and direct URLs, returning a structured list.
  • Anti-Spam Verification: Before sharing to any group, backend/lib/history.js checks if the target URL was posted to that group within the cooldown window (e.g. 7 days).
  • Post Pipeline: Navigates to target group page, opens composition modal, enters text, waits for link preview card rendering, and either clicks Publish (Live mode) or skips publish (Dry-Run mode).
  • Live Telemetry: All log events pass through WebSocketLogger, broadcasting JSON payloads to connected browser dashboard clients.

🤖 Core Global Agent Rules & Guidelines

Mandatory architectural and code quality rules enforced across all AI Agents (Antigravity, Claude Code, Cursor, Windsurf) working on this repository.

📦 1. Modular Frontend File Structure
Strict Rule
  • No Monolithic Frontend Files: Never write frontend script files exceeding 150 lines of code.
  • Single-Responsibility ES Modules: Divide scripts under frontend/js/:
    • api.js: REST API client wrappers.
    • groups.js: State management & group list DOM rendering.
    • terminal.js: Real-time UI log viewer component.
    • websocket.js: WebSocket connection & auto-reconnect handler.
  • Module Loading: Include the main entry point in HTML via <script type="module" src="app.js"></script>.
🧩 2. Reusable Automation Modules
Architecture Standard
  • Decoupled Logic: Keep automation infrastructure independent from specific business logic to maximize reusability across projects.
  • BrowserManager: Manages Playwright persistent browser context and Chrome profiles.
  • HistoryManager: Manages anti-spam history de-duplication and JSON disk storage.
  • WebSocketLogger: Manages real-time log event broadcasting to dashboard clients.
🎨 3. UI/UX Design Standards
Visual Excellence
  • Rich Aesthetics: Modern dark mode with harmonious color palettes, subtle gradients, glassmorphism, and responsive typography (Inter / JetBrains Mono).
  • Micro-Animations: Smooth state transitions, hover effects, and clean active tabs.
  • No Placeholders: All UI mockups and elements must be complete and fully functional.
🛡️ 4. Code Quality & Verification
Quality Assurance
  • Empirical Verification: Never declare success without running build/test verification commands.
  • Log Inspection: Inspect exact stack traces before diagnosing errors; no superficial symptom patches or silent exception swallowing.
  • Preserve API Contracts: Update all invocation sites when function signatures change.
